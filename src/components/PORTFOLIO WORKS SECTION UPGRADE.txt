================================================================================
MASTER IMPLEMENTATION PLAN: PORTFOLIO WORKS SECTION UPGRADE
================================================================================

--------------------------------------------------------------------------------
OVERVIEW & OBJECTIVES
--------------------------------------------------------------------------------
1. Eliminate the generic card-based grid layout.
2. Adopt a zero-click, unfolded technical specification layout for top works.
3. Keep the homepage concise by pairing spotlight works with a secondary archive grid.
4. Implement a fullscreen modal overlay (Expanded Archive Viewport) for "Explore All Works" 
   with real-time search, category filters, and a technical data table.
5. Align completely with dark mode, monospaced typography, and brutalist developer aesthetics.


--------------------------------------------------------------------------------
PHASE 1: DATA STRUCTURE (projectsData.js)
--------------------------------------------------------------------------------
Centralize all project items into a single array to feed both the main page 
and the full archive modal.

[Data Model Schema]
- id (string)
- year (string)
- title (string)
- subtitle (string)
- category (string) // Web Dev, Desktop Dev, App Dev, Networking, System Admin
- featured (boolean) // true = Spotlight (Full Spec), false = Secondary / Archive
- image (string)
- overview (string)
- architecture (array of strings)
- tech (array of strings)
- demoUrl (string)
- codeUrl (string)

use the const projects as it is

Target: Top 2-3 projects (e.g., BUCS MCC, Rental Management System)

[Layout Pattern]
- Alternating 2-column grid (60% Image Preview | 40% Technical Spec)
- Row 1: Image Left | Details Right
- Row 2: Details Left | Image Right

[Exposed Information (100% Upfront)]

--------------------------------------------------------------------------------
PHASE 4: FULLSCREEN ARCHIVE MODAL (AllWorksModal.jsx)
--------------------------------------------------------------------------------
Target: Full catalog takeover view

[Modal Behavior & Structure]
1. Fullscreen Overlay: Fixed viewport takeover (`fixed inset-0 z-50 bg-zinc-950`).
2. Body Scroll Lock: Disable body scrolling when modal active (`overflow: hidden`).
3. Keyboard Event: Dismiss modal on pressing `Escape` key.
4. Top Bar: Title `[ JEDT.ARCHIVE ] / COMPLETE CATALOGUE` and `[ CLOSE ✕ ]` button.

[Interactive Controls]
- Search Input: Filter projects by title or technology keyword in real-time.
- Category Pills: Filter tabs ([ ALL ], [ WEB DEV ], [ DESKTOP DEV ], [ NETWORKING ]).

[Non-Table Interactive Grid Layout]
- 2-Column Responsive Grid (grid-cols-1 md:grid-cols-2 gap-6)
- Each tile features:
  * Header metadata line (Year // Category)
  * Bold project title with emerald color hover state
  * Brief 2-3 line overview
  * Monospaced environment pills ([React], [Laravel], [MySQL])
  * Direct action links ([ LIVE DEMO → ])

--------------------------------------------------------------------------------
PHASE 5: RESPONSIVE & STYLING FINE-TUNING
--------------------------------------------------------------------------------
- Mobile Viewport (< 768px):
  * Stack spotlight rows vertically (Image on top, details underneath).
  * Hide lower-priority columns in the modal table (e.g., Built With) to avoid horizontal overflow.
- Style Tokens:
  * Backgrounds: `bg-zinc-950`, `bg-zinc-900`
  * Text & Accents: `text-white`, `text-emerald-400`, `text-zinc-400`
  * Borders: `border-zinc-800` (Strict 90-degree corners, `rounded-none`)
  * Typography: Mixed Sans-Serif Headlines with Monospaced Metadata (`font-mono`)
